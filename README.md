# Friends Intro

An interactive Python terminal program that introduces my personality, interests, and habits.

## Project Goal

Getting to know new people can sometimes feel awkward, especially when both sides don't know much about each other. I want to create a more interactive and engaging way for people to learn about me, rather than relying on typical introductory questions and small talk.

## MVP Scope

The initial version will be a menu-based terminal program that allows users to explore different aspects of my personality at their own pace.

The MVP will include:
- **Background:** Basic information about me.
- **Hobbies:** A selection of my hobbies, with individual descriptions.
- **Behaviors:** A section introducing some of my habits and personality traits.
- **Fun Facts:** Some random facts about me.
- **Input Handling:** Basic validation for user input.

The goal is to deliver a functional and enjoyable introduction experience through a simple terminal interface.

## Future Plans

Features I may consider adding in future versions:
- Interactive multiple-choice questions about my personality and habits.
- A compatibility quiz with a scoring system.
- More personalized responses based on user choices.
- Terminal colors and visual effects.
- Loading animations and progress bars.
- A desktop GUI version.

## Tech Stack

**Programming Language**
- Python

**Libraries and Modules**
- `random`: Generate randomized responses.
- `time`: Add delays and loading effects.
- `sys`: Access system-related functionality.
- `colorama` (optional, future version): Add colors to terminal output.
- `tqdm` (optional, future version): Create progress bars.

**Data Storage**
- Python lists and dictionaries to store personal information and other content.
- No external database or separate data files required for the MVP.

**Data Sources**
- All content will be based on personal information written directly into the program.
- No external APIs or online data sources are required.

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Run the following command:

```bash
python main.py
```

No additional packages are required for the MVP.
